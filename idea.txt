About adversarial prompts
First, I would like to explain the methods of adversarial prompting, clarifying the terminology and outlining the possible approaches. This article summarizes the six main approaches. The summary is based on the paper: Ignore This Title and HackAPrompt: Exposing Systemic Vulnerabilities of LLMs through a Global Scale Prompt Hacking Competition .

Types of adversarial prompts
1. Prompt Leaking:
A prompt technique designed to leak sensitive information contained in prompts that were not intended to be made public. Also known as prompt leaking.

2. Training Data Reconstruction:
A prompting technique that leaks information contained in LLM training data.

3. Malicious Action Generation:
A prompting technique that induces malicious API calls or code generation.

4. Harmful Information Generation:
Prompt Techniques for Outputting Harmful Information to the LLM
While prompt injection and jailbreaking are commonly used terms, many techniques overlap between the two, so this article combines them into one. Please note that this combination is unique to this article.

Prompt injection
Attack techniques that use prompts to hijack the model's output
Many prompt injection techniques can be used with other adversarial prompts as well.
Jailbreak
Technology that produces illegal or ethically problematic output.
The paper considers jailbreaking to be a subset of prompt injection, so this article will treat it that way as well.

5. Token Wasting:
A prompting technique that generates tokens unnecessarily. Outputting a large number of tokens can increase the output cost and unnecessarily prolong the execution time of the LLM.

6. Denial of Service:
A prompting technique that prevents other users from accessing the LLM service.
Related content
The Waluigi Effect:
A phenomenon in which, after a LLM is trained to possess a specific desirable property, it can easily derive the opposite property.
